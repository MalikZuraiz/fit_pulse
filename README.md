# 💪 FitPulse — Fitness & Wellness App

FitPulse is a modern fitness & wellness app designed to help users track their daily health goals and stay consistent with healthy habits.  
This is a personal portfolio project showcasing clean UI, smooth UX, and essential wellness features.

---

## ✨ Overview

FitPulse focuses on simplicity, habit consistency, and visual motivation.  
It allows users to:

- Track fitness statistics
- Monitor hydration
- Follow daily goals
- Maintain streaks
- Earn achievements
- Stay mindful through progress cards

---

## 🌟 Key Features

| Feature | Description |
|--------|-------------|
📊 Fitness Dashboard | Overview of daily progress  
💧 Hydration Tracking | Track daily water intake  
🔥 Streak System | Build consistent habits  
🏅 Achievements | Stay motivated with reward badges  
🔔 Smart Reminders | Stay on track with alerts  
🌙 Modern UI | Glass-morphism dark theme  
⚡ Smooth UI | Clean navigation & animations
